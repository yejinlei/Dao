## 三、四道质检流水线

每部经文必须依次经过四道质检，全部合格方可上库：

1. **① 初译Agent**
   - 职责：将古文道经逐句译为现代汉语白话
   - 要求：逐句对应、不漏句、不臆造；咒语/圣号/宝号/真君名/地狱名保留原文
   - 输出：格式为「原文段落 + 【译文】 + 白话译文段落」

2. **② 术语校对Agent**
   - 职责：统一道教术语译法
   - 核查要点：
     - "炁" 不译为"气"（道功/内丹/先天语境用"炁"，后天吐纳呼吸可用"气"）
     - 真人/真君/天尊/帝君等圣号不简化
     - 内丹术语（铅汞、坎离、龙虎、黄婆、金公、婴儿、姹女等）统一
     - 三界/九幽/三途/五道/七魄/三尸/八景/二十四治等神谱体系一致
     - 年号/朝代/人名/地名保留原字
   - 输出：术语问题清单+修正后译文

3. **③ 逐句对照校对Agent**
   - 职责：对照原文逐句核对译文
   - 核查要点：漏译句、错译关键字、增译原文没有的意思、把道家术语误译为佛教用语、经文段落对齐
   - 输出：逐句问题清单+修正后译文

4. **④ 流畅度盲校Agent**
   - 职责：不看原文只读译文，润色流畅度
   - 核查要点：语句通顺自然、无翻译腔、无欧化长句、符合中文白话表达习惯、术语保留前提下可读性强
   - 输出：润色后译文+可读性评分（1-5分，需≥4分方可上库）

## 四、译文格式规范
```
<经名>
<白话译文：经名介绍、解题、背景说明1-2段>

【译文】
<白话正文，按段落对应原文>
<原经文段落>
<译文段落>
...
<经文终>

<校译记：列出本次翻译中特殊术语的处理、底本传抄讹误的校勘>
```

## 五、批次管理
- 每次并行派发3-6个子Agent，每个Agent翻译/校对若干部经
- 按字数升序优先翻译短篇经文（<1万字优先）
- 每批完成后：写入译文文件 → 更新 sutras.json 标记为translated → 更新进度追踪日志 → 推送到GitHub Pages
- 批次编号：B013 开始（前12批已完成170部+初译，B013起为全藏流水线）

## 六、质量标准
- 完整性：原文段落无遗漏
- 准确性：术语统一、关键字词不误译
- 可读性：白话流畅、无语病、翻译腔去除
- 格式规范：严格遵循上述格式
