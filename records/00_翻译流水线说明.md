# 道藏白话精译工程 · 翻译流水线说明

## 一、工程目标
- 对《正统道藏》核心短篇道经进行白话精译
- 每部经建立「原文 + 白话译文」对照
- 提供在线阅读：原文 / 注音 / 对照 / 白话 / 本体五种模式
- 全流程可追溯、可复核、可持续扩充

## 二、多Agent流水线架构（四道质检）

### 阶段一：初译 Agent
- **任务**：逐段将古文道经译为现代汉语白话
- **要求**：
  - 保持经文原意，不增不减
  - 道教专有术语（炁、天尊、真人、劫、三界、三清、酆都、罗酆、符箓、科仪等）首次出现时加注释或保留术语
  - 咒语、宝诰、圣号、符文、真言、宝号保留原文不译，以【咒语】标注
  - 每段原文对应一段白话，格式为【白话译文】+ 分段译文
- **输出**：初译稿（写入 translations/core/xxx.txt）

### 阶段二：术语校对 Agent（初校）
- **任务**：对初译稿进行道教术语一致性校验
- **校对要点**：
  - 炁 → 统一译为"先天一炁/真气"，不译为"气"（呼吸之气）
  - 天尊/真人/真君/元君/道君 → 尊号保留，不简化为"神/仙"
  - 劫/万劫 → 译为"劫数/极长的时间"，不译为"灾难"
  - 三清/玉清/上清/太清 → 保留专名，不泛化
  - 三界/十方/三十二天 → 保留道教天界专名
  - 酆都/罗酆/九幽/地狱 → 道教地狱专名保留
  - 符箓/咒诀/法印/科仪/存思/内丹/外丹 → 道教术语保留并首次加注
  - 忠孝/净明/无为/自然/性命/铅汞/坎离/龙虎 → 道教核心概念准确翻译
- **输出**：术语校对记录（写入 records/03_术语校对日志.md）

### 阶段三：逐句对照校对 Agent（二校）
- **任务**：逐句对照原文与译文，检查错译、漏译、增译
- **校对要点**：
  - 对照原文逐句核对，标记漏句
  - 检查数字、名号、方位、神名是否一致
  - 校勘底本传抄讹误（如"炁/氣"、"浄/淨/净"异体字统一）
  - 诗句/偈颂押韵语义通顺
  - 科仪文书格式（举/念/白/和/宣/偈/赞）正确标注
- **输出**：逐句对照校对记录（写入 records/04_逐句对照校对日志.md）

### 阶段四：流畅度盲校 Agent（三校/盲校）
- **任务**：不看原文、只读译文，检查白话流畅度、可读性
- **校对要点**：
  - 语句通顺，符合现代汉语表达习惯
  - 没有翻译腔、没有硬译古文语序
  - 没有错别字、标点错误
  - 段落衔接自然，文意连贯
  - 普通读者可以读懂，不需要古文基础
- **输出**：盲校记录（写入 records/05_流畅度盲校日志.md）

### 定稿入库
- 四道质检全部通过后，标记 quality = "合格"
- 更新 sutras.json 的 translated = true
- 更新进度记录
- 推送至 GitHub Pages 上线

## 五、质量标准
- **完整性**：原文每一句都有对应的白话译文，无漏译
- **准确性**：术语准确，符合道教教义，不望文生义
- **通顺性**：白话流畅自然，普通读者可读
- **一致性**：同一术语在全藏中译法统一
- **可追溯**：每部经的翻译、校对记录完整存档
