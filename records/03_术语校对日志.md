## 术语统一规范

| 术语 | 统一译法 | 说明 |
|------|----------|------|
| 炁 | 真气/先天一炁 | 道教"炁"指先天能量，不同于后天呼吸"气" |
| 天尊 | 天尊（保留尊号） | 道教至高神尊号，不译为"神/上帝" |
| 真人 | 真人 | 修道成真之人，不译为"仙人"泛称 |
| 真君/元君/道君 | 保留原尊号 | 男女仙真尊称 |
| 劫/万劫 | 劫数/极长时间 | 不译为"灾难" |
| 三清 | 三清（玉清/上清/太清） | 道教最高神团，保留专名 |
| 三界 | 三界（欲界/色界/无色界） | 道教天界划分，保留专名 |
| 三十二天/三十六天 | 保留专名 | 道教天界体系 |
| 酆都/罗酆/九幽 | 道教地狱专名，保留 | 不译为"地狱/阴间"泛称 |
| 符箓/法印/咒诀 | 保留术语 | 道教法术用语 |
| 存思/存想 | 存思/观想 | 道教内炼方法 |
| 内丹/外丹 | 保留术语 | 丹道流派 |

| 性命 | 性功与命功 | 内丹修炼两大方面 |
| 无为/自然 | 保留道家核心概念 | 不泛化为"顺其自然" |
| 忠孝/净明 | 保留净明道核心概念 | 净明道以忠孝为本 |
| 科仪/斋醮 | 保留术语 | 道教仪式 |
