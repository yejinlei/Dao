# 北极真武佑圣真君礼文

## 【前言】

《北极真武佑圣真君礼文》，撰人不详，一卷，为道教斋醮科仪文献，收录于《正统道藏》洞神部威仪类。全篇以礼赞北极真武佑圣真君（玄天上帝）为核心：先皈命三清、圣父圣母及真武圣号，继而依次诵持"修真十戒"、逐戒忏悔，复皈命十方圣众，终以发愿、回向收束。其赞文兼融星辰崇拜（虚危二宿、水火二精、壬癸甲庚）与劝善戒恶之教，是研究真武信仰及宋元以降道教忏悔科仪的重要文本。

## 【译文】

### 一、举法事如式

"举法事如式"——依照科仪，如法举行法事。

### 二、启请文

伏闻天关渺漠，非言语之能交。
→ 我伏地听闻：天关（北极天枢之门）遥远渺茫，不是言语所能通达。乾象昭明，惟精诚之可格。
→ 天象昭著光明，唯有精诚可以感通。

灵神力夙称於广大，而祥光普赐於照临。
→ 神灵之力素来以广大著称，祥瑞之光普照临下。

凡在庇麻，敢忘信奉。
→ 凡蒙庇庥（庇护）者，岂敢忘怀信奉。

恭惟镇天真武，治世福神，玉虚师相，玄天上帝，至灵赫赫，盛德巍巍。
→ 恭惟镇天真武、治世福神、玉虚师相、玄天上帝：至灵赫赫，盛德巍巍。

称大将於上穹，为福神於下土。
→ 在天上被尊为大将，在人间作为福神。

六通四辟，无愿不从。万国群生，有求皆应。
→ 六通四辟（六合通达、四方开辟），有愿无不顺从；万国群生，有求皆得感应。

今斋官某，肃严蓬宇，敬运葵诚。
→ 今有斋官某某，庄严道场，恭敬奉上如葵藿向阳般的赤诚。

望玄极以皈依，仰威容而赞礼。
→ 仰望玄极而皈依，仰瞻威容而赞礼。

炉烟缥缈，期至信以潜通。
→ 炉烟缥缈，期望以诚挚之心暗中感通。

磬韵激扬，想洪音之高彻。
→ 磬声激扬，想象洪亮之音高彻云天。

伏愿神明如在，肸蠁来临。
→ 伏愿神明如临在上，肸蠁（神灵感应之气）来临。

鉴此际之精虔，削多生之罪对。
→ 鉴察此时之精诚虔敬，削除多生以来的罪业对报。

道场严洁，诚敬肃将。恭对高真，一心赞礼。
→ 道场庄严洁净，虔诚恭敬地奉行；恭敬面对高真，一心赞礼。

### 三、举金阙化身天尊

"举金阙化身天尊"——唱举"金阙化身天尊"圣号。

#### （一）志心皈命礼 · 虚无自然元始天尊

志心皈命礼。至尊至圣，无古无今，统五十亿之天君，积百千万之梵炁。立混成教本，作极道宗师。端严法相现慈悲，璨烂圆光昭日月。静中说法，五明宫内列真仙。空里谈经，一颗珠中藏世界。（和：）
→ 至诚皈依顶礼。至尊至圣，无古无今，统领五十亿之天君，积集百千万之梵炁。建立"混成"之教本，作至高之道的宗师。端严法相显现慈悲，灿烂圆光照耀日月。静中说法，五明宫内罗列真仙；空中谈经，一颗宝珠之中含藏世界。（和：）

**圣号**：大罗天上金阙宫中虚无自然元始天尊。

#### （二）志心皈命礼 · 玉宸道君灵宝天尊

志心皈命礼。强名曰道，尊以为君，居上清七宝台，为三洞九真主。广说三乘教，宏开众妙门。花冠传万变之名，霞被焕五云之彩。升真度圣，为上下之品阶。保国宁家，超始终之劫运。（和：）
→ 至诚皈依顶礼。强名之为"道"，尊奉以为君；居上清七宝台，为三洞九真之主。广为宣说三乘教法，大开众妙之门。花冠传万变之名号，霞帔焕发五云之彩。升举真仙、超度圣众，为上下之品阶；保国安家，超越始终之劫运。（和：）

**圣号**：大罗天上金阙宫中玉宸道君灵宝天尊。

#### （三）志心皈命礼 · 太上老君道德天尊

志心皈命礼。虚无变化，冥寂玄通，为教父於泰清，作医王於三界，生成万类，总领群真。回骸起死而枯骨沾恩，走篆飞符而邪魔灭迹。显青羊於蜀国，度紫炁於函关。还淳返朴，谈道德五千言。校罪论功，为洞神十二部。（和：）
→ 至诚皈依顶礼。（道）虚无变化，冥寂玄通，在泰清天为教父，在三界作医王；生成万类，总领群真。回骸起死，使枯骨沾恩；走篆飞符，使邪魔灭迹。显化青羊于蜀国，度化紫炁于函关。还淳返朴，宣说《道德》五千言；校罪论功，为洞神十二部经。（和：）

**圣号**：大罗天上金阙宫中太上老君，道德天尊。

#### （四）志心皈命礼 · 圣父太初真君圣母太极元君高上玉皇天尊

志心皈命礼。道本玄元始，名居太极先，事天尊於赤明劫初，正王位於静乐国内。感日光之瑞应，示有本而有源。生圣嗣之，神灵现至，尊而至重。（和：）
→ 至诚皈依顶礼。道本于玄元始（道之根本始于玄元），名位居太极之先；在赤明劫初侍奉天尊，在静乐国内正登王位。感应日光之瑞应，昭示有本有源；生下圣嗣（真武）之神灵，显现至尊至重之相。（和：）

**圣号**：圣父太初真君圣母太极元君高上玉皇天尊。

#### （五）志心皈命礼 · 镇天真武治世福神玉虚师相玄天上帝

志心皈命礼。玄元应化，武曲昭灵，变现八十一身，经历六百万岁。祥开皎日，储神静乐。国中炁受三无，托质广寒宫内。道配乾刚之生育，德同坤厚之载持。道德本於自然，威灵慑於万有。周行六合，考校三元。愿力无边，神功第一。（和：）
→ 至诚皈依顶礼。（真武）玄元应化，武曲昭灵，变现八十一身，经历六百万岁。祥瑞如皎日而开，储神于静乐国中；炁受三无，托质于广寒宫内。其道配乾刚之生育，其德同坤厚之载持。道德本于自然，威灵震慑万有。周行六合，考校三元。愿力无边，神功第一。（和：）

**圣号**：镇天真武治世福神玉虚师相玄天上帝。

#### （六）赞咏

广寒宫里钟三炁，静乐天中禀日光。
虚无变化合自然，道德尊崇无与等。
上配乾刚生庶物，下同坤厚载黎元。
威容赫奕妙难思，誓断妖魔济群品。
→ 广寒宫里钟聚三炁，静乐天中禀受日光。
→ 虚无变化合乎自然，道德尊崇无与伦比。
→ 上配乾刚生育万物，下同坤厚承载黎民。
→ 威容赫奕妙不可思，誓断妖魔济度群品。

### 四、修真第一戒

谨按修真第一戒云：不得阴盗潜谋，害物利己。伏念某多生以来，曾犯此戒。今礼高真，虔诚忏悔。仗此道恩，普垂赦宥。
→ 谨按修真第一戒所说：不得暗中盗窃、阴谋图谋，损害他物以利己。伏念我某某多生以来，曾犯此戒。今礼敬高真，虔诚忏悔。仰仗此道之恩，普垂赦宥。

暗计潜谋阴害物，无边罪业实难逃。
臣今皈命礼高真，忏悔愿除诸罪业。
→ 暗中算计、阴谋、暗害他物，无边罪业实难逃脱。
→ 臣今皈命礼敬高真，忏悔发愿消除种种罪业。

### 五、修真第二戒

志心皈命礼。大罗境上，无欲宫中，易号假名，度人济物。历春秋之六七，成功行於三千。名上彻於玉皇，位特加於玄武。（和：）
→ 至诚皈依顶礼。（真武）居大罗境上、无欲宫中，易号假名，度人济物。历经六七（四十二）春秋，功行成就于三千之数。名号上达玉皇，位号特加"玄武"。（和：）

**圣号**：镇天真武治世福神玉虚师相玄天上帝。

大罗境上神仙裔，无欲宫中变化身。
度人济物显神灵，走篆飞符兴道法。
细若虫鱼蒙大造，微虽草木荷洪恩。
功成行满冠群仙，玉帝加封玄武号。
→ 大罗境上的神仙后裔，无欲宫中的变化之身。
→ 度人济物显现神灵，走篆飞符振兴道法。
→ 细如虫鱼亦蒙大造，微如草木也荷洪恩。
→ 功成行满冠绝群仙，玉帝加封"玄武"名号。

谨按修真第二戒云：不得杀害含生，以充滋味。伏念某多生以来，曾犯此戒。今礼高真，虔诚忏悔。仰仗道恩，普垂赦宥。
→ 谨按修真第二戒所说：不得杀害含生（有生命之物），用来充作滋味。伏念我某某多生以来，曾犯此戒。今礼敬高真，虔诚忏悔。仰仗道恩，普垂赦宥。

杀害含生充口腹，无边罪业实难逃。
臣今皈命礼高真，忏悔愿除诸罪业。
→ 杀害众生以充口腹，无边罪业实难逃脱。
→ 臣今皈命礼敬高真，忏悔发愿消除种种罪业。

### 六、修真第三戒

志心皈命礼。五云座上，八景宫中，听金口之洪音，瞻玉毫之宝相。因妙行殷勤之请，知下民枉横之灾。扫邪魔於七日之中，释滞魄於九泉之下。（和：）
→ 至诚皈依顶礼。（真武）坐五云之座、居八景宫中，听闻金口之洪音，瞻仰玉毫之宝相。因妙行真人殷勤祈请，而知下民枉横之灾。扫除邪魔于七日之中，超释滞魄于九泉之下。（和：）

**圣号**：镇天真武治世福神玉虚师相玄天上帝。

神通广大闻金阙，符命辉华降玉霄。
暂劳宝驾下三天，尽扫妖氛才七日。
复御苍龙朝圣境，载承教勑镇玄天。
尊为无上大将军，永灭邪魔臻道炁。
→ 神通广大声闻金阙，符命辉华降临玉霄。
→ 暂劳宝驾降临三天，尽扫妖氛仅用七日。
→ 复御苍龙朝拜圣境，再承教敕镇守玄天。
→ 尊为无上大将军，永灭邪魔使道炁臻至。

谨按修真第三戒云：不得淫邪败真，秽慢灵炁。伏念某多生以来，曾犯此戒。今礼高真，虔诚忏悔。仰仗道恩，普垂赦宥。
→ 谨按修真第三戒所说：不得行淫邪败坏真元、秽慢灵炁。伏念我某某多生以来，曾犯此戒。今礼敬高真，虔诚忏悔。仰仗道恩，普垂赦宥。

秽浊淫邪伤正炁，无边罪业实难逃。
臣今皈命礼高真，忏悔愿除诸罪业。
→ 秽浊淫邪损伤正炁，无边罪业实难逃脱。
→ 臣今皈命礼敬高真，忏悔发愿消除种种罪业。

### 七、修真第四戒

志心皈命礼。班联四圣，位冠群仙，行大帝之灵符，佩玄元之宝印。有妖必灭，无害不除。雷动风行，云飞电扫。（和：）
→ 至诚皈依顶礼。（真武）班列于四圣之间，位冠于群仙之首，行使大帝之灵符，佩带玄元之宝印。有妖必灭，无害不除。雷动风行，云飞电扫。（和：）

**圣号**：镇天真武治世福神玉虚师相玄天上帝。

班联四圣真勇猛，位冠群仙至贵尊。
顶披绀发示威容，手仗神锋宣咒法。
天罡太乙从驱役，社令城隍听指呼。
魔精妖怪敢当前，电扫雷驱皆灭迹。
→ 班列四圣，真个勇猛；位冠群仙，至贵至尊。
→ 头顶披散绀发示现威容，手执神锋宣扬咒法。
→ 天罡、太乙供其驱役，社令、城隍听其指呼。
→ 魔精妖怪胆敢当前，电扫雷驱皆被灭迹。

谨按修真第四戒云：不得败人成功，析交离亲。伏念某多生以来，曾犯此戒。今礼高真，虔诚忏悔。仰仗道恩，普垂赦宥。
→ 谨按修真第四戒所说：不得败坏他人成功、拆散交谊、离间亲族。伏念我某某多生以来，曾犯此戒。今礼敬高真，虔诚忏悔。仰仗道恩，普垂赦宥。

败坏成功并斗谋，无边罪业实难逃。
臣今皈命礼高真，忏悔愿除诸罪业。
→ 败坏他人功业并设阴谋，无边罪业实难逃脱。
→ 臣今皈命礼敬高真，忏悔发愿消除种种罪业。

### 八、修真第五戒

志心皈命礼。身长千丈，顶戴三台，应虚危二宿之躔，禀水火两精之炁。跨青虬而乘玄骏，显化无方。朝金阙而覆昆仑，去来莫测。（和：）
→ 至诚皈依顶礼。（真武）身长千丈，顶戴三台，上应虚、危二宿之躔次，禀受水、火两精之炁。跨青虬而乘玄骏，显化无方；朝金阙而覆昆仑，去来莫测。（和：）

**圣号**：镇天真武治世福神玉虚师相玄天上帝。

三台辉映无边际，千丈容仪绝等伦。
虚危二宿合英灵，水火两精分秀气。
金阙昆仑随上下，青虬玄骏助威神。
光明遍照於十方，一切人天皆敬仰。
→ 三台辉映无有边际，千丈容仪超绝伦类。
→ 虚、危二宿合其英灵，水、火两精分其秀气。
→ 金阙、昆仑随其上下，青虬、玄骏助其威神。
→ 光明遍照于十方，一切人天皆生敬仰。

谨按修真第五戒云：不得谗毁贤良，露才扬己。伏念某多生以来，曾犯此戒。今礼高真，虔诚忏悔。仰仗道恩，普垂赦宥。
→ 谨按修真第五戒所说：不得谗毁贤良、显露才能、张扬自己。伏念我某某多生以来，曾犯此戒。今礼敬高真，虔诚忏悔。仰仗道恩，普垂赦宥。

谗毁贤良扬己德，无边罪业实难逃。
臣今皈命礼高真，忏悔愿除诸罪业。
→ 谗毁贤良、张扬己德，无边罪业实难逃脱。
→ 臣今皈命礼敬高真，忏悔发愿消除种种罪业。

### 九、修真第六戒

志心皈命礼。神通至大，变化无方，披发跣足俨威容，布斗交乾宣咒语。魁罡激指，护群品於劫始劫终。乾坤游行，臻道炁於天上天下。（和：）
→ 至诚皈依顶礼。（真武）神通至大，变化无方；披发跣足俨然威容，布斗交乾宣扬咒语。魁罡激指，护佑群品于劫始劫终；乾坤游行，使道炁臻于天上天下。（和：）

**圣号**：镇天真武治世福神玉虚师相玄天上帝。

自在神通宜广大，亿千变化固难名。
衣袍披甲俨威容，跣足蹑罡腾玉步。
天上天下臻道炁，劫终劫始剪魔精。
交乾布斗咒言宣，一切狞妖皆缩首。
→ 自在神通宜其广大，亿千变化本难称名。
→ 衣袍披甲俨然威容，跣足踏罡腾起玉步。
→ 天上天下凝臻道炁，劫终劫始剪除魔精。
→ 交乾布斗咒言宣说，一切狞妖皆自缩首。

谨按修真第六戒云：不得饮酒过差，食肉违禁。伏念某多生以来，曾犯此戒。今礼高真，虔诚忏悔。仰仗道恩，普垂赦宥。
→ 谨按修真第六戒所说：不得饮酒过度失度、食肉违背禁戒。伏念我某某多生以来，曾犯此戒。今礼敬高真，虔诚忏悔。仰仗道恩，普垂赦宥。

乐酒无度并食肉，无边罪业实难逃。
臣今皈命礼高真，忏悔愿除诸罪业。
→ 嗜好饮酒无度并食肉，无边罪业实难逃脱。
→ 臣今皈命礼敬高真，忏悔发愿消除种种罪业。

### 十、修真第七戒

### 二十、讽经 · 回向

"讽经　回向"——讽诵经典 · 回向功德。

伏以一声圣号，能消劫劫之灾。众咏真名，可长生生之福。言之难尽，赞亦莫穷。恭按冲科，仰瞻妙相。严陈赞咏之理，备伸忏悔之诚。惟天听之匪遥，冀人心之可格。伏愿惟宏慈之莫大，念群品之可哀。俾荡涤於前非，尽释赦於宿对。丹书纪善，碧简延生。眷属安宁，永处福龄之地。九玄超度，尽离幽暗之乡。以臻诸福，则何福不臻。以灭诸灾，则何灾不灭。千灵拥护，万事亨通。倘副愚衷，敢忘效验。稽首皈依，志心称念。福生无量天尊，不可思议功德。
→ 伏以一声圣号，能消历劫之灾；众口咏赞真名，可增长生生之福。言之难尽，赞亦无穷。恭敬依循冲科（清静科仪），仰瞻妙相；庄严陈说赞咏之理，完备伸展忏悔之诚。惟愿天听并不遥远，冀望人心可以感通。伏愿（高真）广施莫大之宏慈，哀念群品之可悯，使我等荡涤前非，尽得释赦宿世冤对。丹书纪载善行，碧简延注长生。眷属安宁，永处福龄之地；九玄（九代祖先）超度，尽离幽暗之乡。以此臻集诸福，则何福不臻；以此灭除诸灾，则何灾不灭。千灵拥护，万事亨通。倘若副合愚衷，岂敢忘其效验。稽首皈依，至心称念：

福生无量天尊，不可思议功德。

4. **背景补充**：文中"历春秋之六七"指真武历四十二年修行而成道；"静乐国""广寒宫"为真武降生、托质之传说场所；"虚危二宿""水火两精""壬癸甲庚"系以北方七宿与五行方位比附真武神格，均据道教真武信仰通说译出。

5. **存疑字句**：底本数处疑有阙讹或形近致误，如"三无"（或作"三光／三元"）、"臻道无於天上天下"（疑为"道炁"）、"显青羊，准於蜀国"（"准"字疑讹）、"死神力"（疑为"真神力"或衍一字）、第六戒"乐酒无□并食肉"与第七戒"贪求无□"之缺字（据戒文补为"无度""无厌"）。译文斟酌文意处理，未敢径改原文，特此说明以备考订。
