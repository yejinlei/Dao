金丹四百字白话译文：

（此为内丹诗诀，共二十首五言，述结丹次第。以下逐首译其大意。）

【其一】真土擒真铅，真铅制真汞，铅汞归真土，身心寂不动。
→ 以真意（真土）擒取真铅，真铅制约真汞；铅汞同归于真土，身心便寂然不动。

【其二】虚无发下雪，寂静发黄芽，玉炉火温温，鼎上飞紫霞。
→ 虚无之中飘落"白雪"（先天一炁），寂静之中萌发"黄芽"（丹苗）；玉炉之火温温不烈，鼎上飞腾紫霞。

【其三】华池莲花开，神水金波静，夜深月正明，天地一轮镜。
→ 华池中莲蕊绽开，神水之上金波平静；夜深人静、月色正明，天地如同一轮明镜。

【其四】朱砂炼阳气，水银烹金精，金精与阳气，朱砂而水银。
→ 以朱砂炼养阳气，以水银烹炼金精；金精与阳气，不过朱砂与水银两个异名。

【其五】日魂玉兔脂，月魄金乌髓，掇来归鼎中，化作一泓水。
→ 取日魂（玉兔之脂）、月魄（金乌之髓），收取归入鼎中，化作一泓清水。

【其六】药物生玄窍，火候发阳炉，龙虎交会时，宝鼎产玄珠。
→ 药物生于玄关一窍，火候起于阳炉；龙虎交会之时，宝鼎之中产出玄珠。

【其七】此窍非凡物，乾坤共合成，名为神气穴，内有坎离精。
→ 这一窍并非凡物，由乾坤共同合成；名叫"神气穴"，内藏坎离之精。

【其八】木汞一点红，金铅三斤黑，铅汞结丹砂，灿灿紫金色。
→ 木汞一点鲜红，金铅三斤玄黑；铅汞凝结成丹砂，灿灿现出紫金之色。

【其九】家园景物丽，风雨正春时，犁锄不废力，大地皆黄金。
→ 家园景物秀丽，风雨正逢春时；犁锄不废其力，大地尽变黄金。

【其十】真铅生于坎，其用在离宫，以黑而变红，一鼎云气浓。
→ 真铅生于坎（水），其用却在离（火）宫；由黑变红，一鼎之中云气浓厚。

【其十一】真汞产于离，其用却在坎，姹女过南园，手持玉橄榄。
→ 真汞产自离（火），其用却在坎（水）；姹女经过南园，手持玉橄榄。

【其十二】震兑非东西，坎离不南北，斗柄运周天，要人会攒簇。
→ 震兑并非东西之位，坎离也非南北之方；斗柄运转周天，要学人领会"攒簇"（聚五行于一时）之妙。

【其十三】火候不须时，冬至岂在子，及其沐浴法，卯酉时虚比。
→ 火候不必拘于时辰，冬至岂一定在子时？至于沐浴之法，以卯酉二时作虚比罢了。

【其十四】乌肝与兔髓，擒来归一处，一粒复一粒，从微而至着。
→ 取乌肝与兔髓，擒来归合一处；一粒再一粒，由微而至于显著。

【其十五】混沌包虚空，虚空括三界，及寻其根源，一粒如黍大。
→ 混沌包着虚空，虚空括着三界；推寻其根源，不过一粒如黍米大小。

【其十六】天地交真液，日月含真精，会得坎离基，三界归一身。
→ 天地交合而生真液，日月含藏真精；领会坎离之基，则三界都归于一身。

【其十七】龙从东海来，虎向西山起，两兽战一场，化作天地随。
→ 龙从东海而来，虎自西山而起；两兽相战一场，便化作天地随顺之象。

【其十八】金花开汞叶，玉蒂长铅枝，坎离不曾闲，乾坤今几时。
→ 金花绽开汞之叶，玉蒂长出铅之枝；坎离一刻不曾停歇，乾坤运转到今已几多时日？

【其十九】沐浴防危险，抽添自谨持，都来三万刻，差失恐毫厘。
→ 沐浴之时防其危险，抽添火候须自谨守；总共不过三万刻功夫，如有差失便恐相差毫厘。

【其二十】夫妇交会时，洞房云雨作，一载生个儿，个个会骑鹤。
→ 夫妇交会之时，洞房云雨兴起；怀胎一载生下一个婴儿，个个都能骑鹤飞升。
