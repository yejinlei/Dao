# 太上洞玄灵宝三元无量寿经

> 底本出处：《正统道藏》洞玄部本文类。撰人不详，约出于南北朝或隋唐。经文论述修持观慧、离过清净之法，以十德配二十余观行法门，终明受持此经可得无量福寿，是灵宝系观慧修持经典。一卷。

---

## 前言

《太上洞玄灵宝三元无量寿经》一卷，作者失考，约出于南北朝至隋唐间，收入《正统道藏》洞玄部本文类。经文假托太上道君在三元宫中大会说法，有真人仪可（智力无畏）从座而起，请问一切诸法从何而生、如何观行而成道。

太上道君答以"三界诸法皆从道生，若欲求道当修观慧"，随即开示以智慧、慈悲、含忍、行功、修心、善业、精进、饰身、遣情、普心十德为纲，逐一配属二十六种观行法门（远身行法、离口过法、除恶想法、拔逮根法、绝声色法、俭爱欲法、放玩习法、洗垢秽法、无昏惑法、不淫想法、不疑空法、平好丑法、不邪还法、常住无法、绝心想法、习悉意法、善防言法、不乱转法、不悟念法、不彼念法、不悠想法、无常定法、无常的法、无常顾法、不追怀法、无犹豫法、忍不可忍法），每种法皆以十德通贯，共计二百六十种法，皆称"不可称量"。

经文末段总述《洞玄经》为天地之源、道德之宗，上圣尊贵、鬼神畏伏，若人能受持读诵、心无懈怠，即得生无量智慧、增无量善因、灭无量业障、消无量烦恼、延无量寿算、长无量福田，世世欢荣、生生快乐。经题中"三元"指三元宫（天、地、水三元，或三宝三元），"无量寿"指受持此经所得寿命福田无量，兼融佛教般若观慧与道教功德福报思想，是南北朝隋唐之际佛道交融的灵宝经典之一。

本次白话精译保留经序-法要-流通三段结构，经中重复叠唱的十德配列法依原文范式译出，道教核心术语（道、观慧、三界、业障、福田、寿算、三元宫、洞玄灵宝等）依道教灵宝经传统保留。

### 流通分

道君说：这《洞玄经》，是天地的源头，道德的宗本，为上圣所尊贵，为鬼神所畏伏。其高出九天之上，其深通九地之下，千变万化，道尽于此。若有人能于此经受持读诵，心无懈怠，即得：
- 生无量智慧，
- 增无量善因，
- 灭无量业障，
- 消无量烦恼，
- 延无量寿算，
- 长无量福田。

世世欢荣，生生快乐。应当恒常恭敬，抄写流传，利益众生，此即为无量功德。

真人听闻此说，信受奉行。

太上洞玄灵宝三元无量寿经竟。

## 校译记

1. **底本讹字校勘**：
   - "是为十种饱声色法"："饱"为"绝"之形讹，依经题"绝声色法"及前后文例改正为"绝声色法"。
   - "复有十种俭爱欲法，可称量"：依前后各段"不可称量"文例，"可"前脱"不"字，译文补"不可称量"。
   - "复有十种检爱欲法"："检"与段首"俭"字通，是俭为敛束义，译文统一为"俭爱欲法"。
   - "八者，市饰身放玩习法""八者，市饰身洗垢秽法""八者，市饰身无昏惑法"：三处"市"字为"饰"字形近衍文，依前后各段"八者，饰身……"文例删。
   - "九者，遗情忍不可忍法"："遗"为"遣"之讹，依前后各段"遣情"改。
   - 第七项"波身行法"：原文"七者精进波身行法"，"波"为"远"之讹，依第一项"远身行法"体例及其他各项"离口过""除恶想"等皆十德通例，改"波"为"远"，归入十远身行法之七。

2. **十德说明**：经中智慧、慈悲、含忍、行功、修心、善业、精进、饰身、遣情、普心十种德行，是贯通全经的纲维，每一观行法门皆以十德逐一开演，共二十七类、二百七十法（原文列二十七段，每段十法），皆称"不可称量"，显示功德无量。译文保留此十德十法的重迭结构，以体现灵宝经特有的重法数、尚功德的风格。

3. **佛道交融术语**：观慧、三界、业障、烦恼、福田、智慧、慈悲、精进、忍等术语，虽多见于佛典，但南北朝灵宝经已普遍吸收使用，成为道教自身教义的组成部分，译文依道教灵宝经语境译出，不另作佛学考辨。

4. **经题释义**："三元"在灵宝经中可指天、地、水三元，亦可指三宝（道、经、师）三元，此处指太上道君说法之"三元宫"；"无量寿"指受持此经所得智慧、善因、寿算、福田皆无量，非仅指寿命绵长，译文在题解中予以说明。
